# Real AI Actions

Every priority page needs a functioning action. A button that only reveals pre-written text does not count.

## V1 actions

### Analyse Work
Input: free-text description of a real task/process.
Output:
- current work breakdown;
- AI-suitable steps;
- human-only steps;
- proposed workflow;
- risks/assumptions;
- implementation sequence;
- value measures.

### Design Workflow
Input: task, tools currently used, frequency, required output.
Output: structured human + AI workflow with checkpoints and failure handling.

### Design Agent
Input: repeatable responsibility and boundaries.
Output: agent purpose, inputs, tools needed, prohibited actions, human hand-offs, test plan.

### Governance Pre-Check
Input: proposed AI use, data involved, audience, decisions affected.
Output: risk questions, controls and approvals to consider. Never present this as legal/compliance approval.

### 90-Day Adoption Plan
Input: team/role context.
Output: discovery, quick wins, capability, champions, controls, rollout and measurement plan.

### Role Learning Plan
Input: role and real work.
Output: practical skill path built around actual tasks, not generic AI theory.

### Value Framework
Input: workflow baseline.
Output: metrics to measure time, quality, cost, risk, adoption and business outcome. Never fabricate results.
