# Company Solution Page Template

## 1. Hero

**{Company} — {Role}**

Small line: `Public role brief • verified {date}`

## 2. What the role is trying to achieve

A tight paraphrase of the public ad. No invented internal facts.

## 3. Our Agent has outlined this

Company-specific solution name.

One paragraph explaining the system we would build around the role.

## 4. The solution

Show only the modules that matter to that role. Rename them in language appropriate to the company/industry.

Each module must answer:
- What input does it take?
- What real work does it do?
- What does it return?
- Where does human judgement remain?
- What would be required to connect it to internal systems?

## 5. Try a real action

At least one working interaction, e.g.:
- Analyse a workflow.
- Build a safe AI workflow.
- Create a 90-day adoption plan.
- Build a role learning plan.
- Run a governance pre-check.
- Design an agent.
- Create an executive value framework.

No fake output. The model processes the visitor's real input.

## 6. What remains human

Explicitly show the accountable decisions that software does not replace.

## 7. Source

Link to the original public role.
