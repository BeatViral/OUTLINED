# ABC AI Adoption System

A workforce-facing system that starts with the real editorial or business task, identifies where AI can help, keeps human editorial/business judgement visible, creates a repeatable safe workflow and turns successful patterns into reusable guidance.

## Core blocks

### Work Discovery
User describes a real task:
- editorial research;
- program brief;
- production/admin workflow;
- internal reporting;
- planning;
- communications.

The system breaks the task into steps and identifies where AI is useful and where it should not be used.

### Safe Workflow Architect
Creates a proposed workflow with:
- inputs;
- AI-assisted steps;
- human checks;
- prohibited/uncertain steps;
- output;
- implementation notes.

### AI Coach
Answers "how would I use AI for this?" in practical task language.

### Safe-Use Pre-Check
Asks about:
- confidential/sensitive information;
- external/public output;
- factual accuracy;
- copyright/IP;
- decisions affecting people;
- required human review.

This is guidance, not ABC policy approval.

### Learning Studio
Turns discovered workflows into role-based practice tasks and playbooks.

### Adoption Intelligence
Defines what to measure:
- use;
- repeated use;
- workflow completion;
- quality;
- time;
- support requests;
- abandoned use cases;
- reasons people stop.

No fabricated adoption figures.

## First real interaction

**Analyse a real piece of work**

Visitor describes a task. The agent returns:
1. what it understood;
2. AI-suitable steps;
3. human-only steps;
4. safe workflow;
5. risks/questions;
6. implementation steps;
7. measurements.

## Human judgement

Editorial standards, final publishing decisions, sensitive-source handling and policy interpretation remain with accountable ABC staff.
